# Statistical Analysis of NBA Player Performance: Hypothesis Testing & Data Insights

## Project Overview

This project analyzes NBA player performance statistics using descriptive statistics, data visualization, and hypothesis testing. The analysis explores key basketball performance indicators and examines differences between American and non-American players.

## Objectives

- Analyze NBA player performance using descriptive statistics.
- Explore scoring, assists, rebounds, steals, and blocks.
- Visualize player performance patterns and distributions.
- Apply one-sample and two-sample t-tests to investigate statistical hypotheses.
- Compare performance between American and non-American players.

## Dataset

The project uses NBA player statistics, covering the following performance metrics:

- Points Per Game (PPG)
- Assists Per Game (APG)
- Rebounds Per Game (RPG)
- Steals Per Game (SPG)
- Blocks Per Game (BPG)
- Player nationality or country

The repository also contains an additional dataset related to defensive strategy comparisons. Refer to the corresponding analysis and dataset files to understand its specific use.

## Methodology

### 1. Data Preparation
Prepared the player statistics dataset for analysis and identified the relevant variables.

### 2. Descriptive Statistics
Calculated and examined statistical measures such as mean, median, mode, and standard deviation to summarize player performance.

### 3. Data Visualization
Created visualizations to explore player statistics, distributions, and performance patterns.

### 4. Hypothesis Testing
Applied one-sample and two-sample t-tests to evaluate statistical hypotheses. The analysis included comparisons between American and non-American players, using a 5% significance level where applicable.

### 5. Interpretation
Interpreted the statistical results to identify potential differences in player performance and draw data-driven insights.
